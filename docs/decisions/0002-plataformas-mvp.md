# ADR 0002 — Plataformas do MVP

- **Status:** Aprovada (28/09/2026)

## Decisão

O MVP será publicado para **iPhone (iOS) e Android**. A versão Web do app fica para depois do MVP
(o Expo permite gerá-la a partir do mesmo código). O painel admin é Web desde o início.

## Consequências

- Necessário conta Apple Developer (US$ 99/ano) e Google Play Console (US$ 25, pagamento único) antes do beta.
- Assinaturas dentro do app usam obrigatoriamente o pagamento da Apple/Google (via RevenueCat).
